TABLEAU OFFLINE AI  -  Windows

TO GET THE .EXE (one time):
  1. Double-click BUILD_EXE.bat   (needs Python installed + internet, ~3 min)
  2. Your app appears in the "dist" folder: TableauOfflineAI.exe
  3. That single file is the app. Copy it anywhere and double-click.

TO USE:
  1. Open LM Studio, load a model, start the Local Server (port 1234).
  2. Open TableauOfflineAI.exe, add your CSV/Excel files, type your question, press Solve.

Quick try without building: double-click RUN_WITHOUT_BUILDING.bat
Errors are logged to: %USERPROFILE%\TableauOfflineAI_error.log
